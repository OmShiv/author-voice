# Author Voice 0.1.0 — public beta

Initial release of a shared writing and revision skill for research papers and books.

- Draft directly in the intended voice, revise existing prose, audit a passage, or derive a portable voice profile.
- Preserve evidence, uncertainty, citations, technical notation, and document structure.
- Use the native plugin in Claude Code or supported OpenAI plugin surfaces, upload the skill in Claude chat, or configure a Gemini Gem from the supplied instructions.
- Run the optional offline checker on Markdown, plain text, or LaTeX revisions.

The archives contain the same canonical instructions. No external service, API key, or additional Python package is needed by the local checker.

This is a beta. Local package validation and automated checker tests do not establish editorial quality across models. See the repository's validation record for checks performed and the evaluation suite for reproducible host-level cases. Review changes to meaning and citation associations before publishing a manuscript.
