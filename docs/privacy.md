# Author Voice privacy notice

Effective September 17, 2026. Publisher: Om Shankar Tiwari.

Author Voice is a downloadable package of writing instructions, reference material, and an optional offline Python checker. The package contains no publisher-operated backend, telemetry, analytics, advertising, account system, or external model API calls. Installing the package does not connect it to a publisher service.

When you use Author Voice inside Claude, ChatGPT, Gemini, or another host, that host processes the messages, files, and tool actions you provide under its own terms, privacy settings, and policies. A host may invoke its available document or file tools during an authorized task. This package does not change the host's data handling or give the publisher access to those conversations.

The local checker reads the files named in its command arguments and prints its report to standard output. It makes no network requests. Reports can contain excerpts or protected strings from those files. If you redirect a report into a file, choose a location suitable for the source material.

If you send feedback through the project's [public issue tracker](https://github.com/OmShiv/author-voice/issues), that feedback is public and is handled by GitHub and the project maintainers. Use a small synthetic example when reporting an issue; do not include confidential manuscripts, personal data, or access credentials. The publisher is [Om Shankar Tiwari](https://github.com/OmShiv).

Updates that introduce a new data flow will update this notice. The software version and release notes identify the package you installed.
